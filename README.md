# Centrate

Centering your window. Concentrate on what matters.

The official Centrate website. The app is currently in development.

## Local preview

Run `npm run dev` with Node.js and open http://127.0.0.1:4174.

This is a static website built with HTML, CSS, and JavaScript. No dependencies or build step are required.

## Deployment

GitHub Pages serves the root of the `main` branch. Updates pushed to `main` are deployed automatically.

This repository contains the website only.
